# Instruções para adicionar som de notificação

Para usar som de notificação no projeto, você precisa:

1. Adicionar um arquivo de áudio em `assets/notification.mp3`
2. O arquivo deve ser um arquivo de áudio MP3 válido

Se não tiver um arquivo de áudio, o app ainda funcionará, mas pulará a reprodução do som.

## Para testes rápidos:

Você pode usar qualquer arquivo de áudio MP3. Alguns sites oferecem sons livres:
- https://freesound.org
- https://www.zapsplat.com

Ou gerar um com ferramentas online:
- https://www.ttsmp3.com

Basta adicionar o arquivo em: `assets/notification.mp3`
